Qué se hará en el proyecto

La aplicación incluirá las siguientes funcionalidades principales:

Crear una página de inicio que sirva como acceso al resto de la aplicación.
Mostrar un listado completo de ejercicios en una tabla generada automáticamente.
Permitir la búsqueda de ejercicios escribiendo parte de su nombre en un campo de texto.
Incluir un filtro por músculo principal mediante un menú desplegable.
Ofrecer la opción de ordenar los ejercicios alfabéticamente en orden ascendente o descendente.
Mantener los valores introducidos en el formulario después de realizar una búsqueda o filtro.
Permitir acceder a una página de detalle individual para cada ejercicio.
Mostrar en la vista de detalle información completa como instrucciones, músculos implicados y material necesario.
Controlar errores en caso de que se acceda a un ejercicio que no exista.

De qué manera se desarrollará

El desarrollo de la aplicación se realizará de la siguiente forma:

Utilizar Python con Flask para gestionar el funcionamiento general de la aplicación.
Guardar los datos de los ejercicios en un archivo JSON en lugar de usar una base de datos.
Leer y procesar ese archivo para mostrar la información en la web.
Recoger los datos que introduce el usuario en los formularios para aplicar búsquedas y filtros.
Filtrar y ordenar los ejercicios según las opciones seleccionadas.
Mostrar los resultados de forma clara en las páginas correspondientes.
Organizar la estructura de las páginas para que todas mantengan un diseño común y coherente.
